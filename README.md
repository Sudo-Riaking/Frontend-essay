# Frontend-essay

Ce dépôt contient plusieurs mini-projets front-end organisés par dossier :

- `roses-site/` : petit site de présentation avec pages `index.html`, `about.html`, `gallery.html`, `contact.html`
- `personal-portfolio/` : site perso avec pages `index.html`, `profil.html`, `contact.html`
- `js-demo/` : démonstration JavaScript simple dans `index.html`
- `tp1-store/` : page de projet `index.html` pour le mini-site de boutique

> Remarque : les fichiers CSS et JavaScript associés ne sont pas présents dans le dépôt actuel.

Les fichiers originaux ont été déplacés pour mieux séparer chaque mini-projet.
